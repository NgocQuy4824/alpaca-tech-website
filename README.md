# AlpacaTech Website

AlpacaTech corporate website — cloned from `https://www.alpaca-tech.ai/en` using AI website cloner template.

## Tech Stack

- **Next.js 16** — App Router, React 19, TypeScript strict
- **Tailwind CSS v4** — oklch design tokens
- **Fonts** — Noto Sans JP, Montserrat

## Pages

| URL | Route |
|---|---|
| `https://www.alpaca-tech.ai/en` | `/en` |
| `https://www.alpaca-tech.ai/en/company` | `/en/company` |
| `https://www.alpaca-tech.ai/en/recruit` | `/en/recruit` |
| `https://www.alpaca-tech.ai/en/news` | `/en/news` |

## Commands

```bash
npm install    # install deps
npm run dev    # dev server → http://localhost:3000/en
npm run build  # production build
npm run check  # lint + typecheck + build
```
